# Diet Agent v0.5 扩展设计

> **目标**：让猫猫虫从"会调工具的 LLM"进化成"懂你的饮食教练"
> **核心方向**：长期记忆 + 主动 Agent + RAG 知识库
> **新增代码量预估**：约 2000-3000 行
> **依赖新增**：`@xenova/transformers`、`node-cron`
> **状态**：设计阶段

---

## 总览

本期扩展把 DietAgnet 从单 Agent 工具调用模型，升级为具备**长期记忆、主动行为、知识库支撑**的进阶 Agent 应用：

- 🧠 **会记忆**：记住偏好、过敏、习惯，跨会话保留
- 🤖 **会主动**：定时提醒、异常告警、成就鼓励
- 📚 **会查证**：营养数据来自权威成分表，建议来自膳食指南
- 🎯 **更专业**：从"会聊天的工具调用 LLM"进化成"懂你的饮食教练"

## 一、Dexie 数据库扩展 Schema

现有 `diet-agent-planning` 数据库基础上扩展，**版本号升到 v3**。

```typescript
// src/renderer/stores/db.ts（新建，统一管理 Dexie）
import Dexie, { Table } from 'dexie';

// ============ 长期记忆 ============
export interface Memory {
  id?: number;
  type: 'fact' | 'preference' | 'habit' | 'allergy' | 'dislike';
  content: string;              // 自然语言描述
  confidence: number;           // 0-1，Agent 推断的置信度
  source: 'user_explicit' | 'agent_inferred' | 'imported';
  tags: string[];               // ['breakfast', 'protein']
  createdAt: number;
  updatedAt: number;
  lastUsedAt?: number;          // 最后一次被 recall 命中
  hitCount: number;             // 被引用次数，做权重排序
}

// ============ 知识库（RAG） ============
export interface KnowledgeChunk {
  id?: number;
  source: 'food_composition' | 'dietary_guideline' | 'recipe' | 'disease_diet';
  category: string;
  title: string;
  content: string;
  metadata: Record<string, any>; // 食物条目时存营养字段
  tags: string[];
  embedding: Float32Array;       // 512 维 bge-small-zh
  embeddingModel: string;        // 便于将来换模型
  createdAt: number;
}

// ============ 主动触发事件日志 ============
export interface ProactiveEvent {
  id?: number;
  trigger: 'cron' | 'context' | 'rule';
  ruleId: string;
  firedAt: number;
  delivered: boolean;
  userResponse?: 'engaged' | 'dismissed' | 'snoozed';
  payload: Record<string, any>;
}

// ============ Agent 工作记忆（短期会话摘要） ============
export interface SessionSummary {
  id?: number;
  sessionId: string;
  summary: string;
  keyEvents: string[];
  createdAt: number;
}

export class DietAgentDB extends Dexie {
  memories!: Table<Memory, number>;
  knowledge!: Table<KnowledgeChunk, number>;
  proactiveEvents!: Table<ProactiveEvent, number>;
  sessionSummaries!: Table<SessionSummary, number>;

  constructor() {
    super('diet-agent-v3');
    this.version(3).stores({
      memories: '++id, type, *tags, createdAt, hitCount',
      knowledge: '++id, source, category, *tags',  // embedding 不建索引
      proactiveEvents: '++id, ruleId, firedAt, delivered',
      sessionSummaries: '++id, sessionId, createdAt',
      profiles: '++id, createdAt',
      planVersions: '++id, profileId, version, createdAt',
    });
  }
}
export const db = new DietAgentDB();
```

### 2.3 提取策略（让 Agent 自己沉淀记忆）

每轮对话结束后，**触发隐式提取**：

- 用一个轻量 prompt 让 LLM 判断："本轮对话中是否有应被长期记住的事实？"
- 输出 JSON：`[{ type, content, confidence }]`
- 调用 `remember()` 入库
- 这一步独立于主对话流，不阻塞用户响应

### 3.4 防骚扰机制

- **静音时段**：默认 23:00-7:00 不打扰
- **冷却时间**：每条规则有 `cooldownHours`
- **用户开关**：设置页里可分别开关各类提醒
- **学习用户偏好**：连续 3 次 `dismissed` 自动降级该规则优先级

### 4.2 Embedder 封装

模型选型：**bge-small-zh-v1.5**（33M 参数，~95MB，纯 CPU 跑，单次推理 20-50ms）

```typescript
// src/renderer/knowledge/embedder.ts
import { pipeline, env } from '@xenova/transformers';

// 关键：让模型文件从本地 resources 加载，不联网
env.allowRemoteModels = false;
env.localModelPath = '/models/';

class Embedder {
  private extractor: any = null;
  private modelName = 'Xenova/bge-small-zh-v1.5';

  async init() {
    if (this.extractor) return;
    this.extractor = await pipeline('feature-extraction', this.modelName, {
      quantized: true,  // int8 量化版，体积 -60%、速度 +50%
    });
  }

  async embed(text: string): Promise<Float32Array> {
    await this.init();
    const result = await this.extractor(text, {
      pooling: 'mean',
      normalize: true,  // L2 归一化后点积 = 余弦相似度
    });
    return result.data;
  }

  async embedBatch(texts: string[]): Promise<Float32Array[]> {
    return Promise.all(texts.map(t => this.embed(t)));
  }
}
export const embedder = new Embedder();
```

### 4.3 Retriever（混合检索）

```typescript
// src/renderer/knowledge/retriever.ts
export interface RetrievalQuery {
  query: string;
  sources?: KnowledgeChunk['source'][];
  tags?: string[];
  topK?: number;
  minScore?: number;
}

export async function retrieve(q: RetrievalQuery): Promise<RankedChunk[]> {
  const queryVec = await embedder.embed(q.query);

  // 1. 候选集筛选（结构化预过滤，降低暴力计算量）
  let candidates = await db.knowledge.toArray();
  if (q.sources) candidates = candidates.filter(c => q.sources!.includes(c.source));

  // 2. 暴力余弦
  const scored = candidates.map(c => ({
    chunk: c,
    score: dotProduct(queryVec, c.embedding),
  }));

  // 3. 标签提权（混合检索的"混合"在这里）
  if (q.tags?.length) {
    scored.forEach(s => {
      const overlap = q.tags!.filter(t => s.chunk.tags.includes(t)).length;
      s.score += overlap * 0.05;
    });
  }

  return scored
    .filter(s => s.score >= (q.minScore ?? 0.4))
    .sort((a, b) => b.score - a.score)
    .slice(0, q.topK ?? 5);
}

function dotProduct(a: Float32Array, b: Float32Array): number {
  let sum = 0;
  for (let i = 0; i < a.length; i++) sum += a[i] * b[i];
  return sum;
}
```

## 八、风险与缓解

| 风险 | 缓解 |
|---|---|
| `@xenova/transformers` 在 renderer 加载 WASM 可能被 CSP 阻拦 | 在 `electron.vite.config.ts` 配置 CSP 允许 `wasm-unsafe-eval`，或把嵌入跑在 worker |
| ONNX 模型让安装包变大 ~95MB | 用 quantized 版（int8）压到 ~40MB；或首次启动按需下载 |
| 食物成分表数据来源版权 | 用公开科研数据集 + 注明出处；或参考已开源的中文食物营养库 |
| 记忆系统提取错误事实 | 提取时要求 LLM 输出 confidence，<0.6 的不入库；用户可在设置页删除 |
| 主动提醒过于打扰 | 默认全部开关 off，引导用户主动开启；严格冷却与静音时段 |
| Dexie 迁移 v2 → v3 可能丢数据 | 写 `upgrade` 函数，先备份现有数据；老用户首次升级有提示 |
